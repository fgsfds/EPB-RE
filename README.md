# EPB-RE

Byte-identical reconstruction of both DOS `GAME.EXE` builds of Extreme Paintbrawl.

| Version | CRC32 |
| --- | --- |
| Retail 1.0 | `D6CC00A8` |
| 1.01 / 1.1 / 1.91 | `4228EC31` |
